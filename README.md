# BAS Feature Flows

สมุดติวแบบเล่นได้สำหรับเว็บ BAS (Building Advanced Solution) งานกลุ่มวิชา 953104 อธิบาย 7 ฟีเจอร์ที่ต้องสอบ และฟีเจอร์เสริมอีก 2 ตัว คือเปลี่ยนธีมกับเปลี่ยนภาษา

## ทำอะไรได้บ้าง

- **เล่นเว็บจริงข้าง flowchart** เปิดเว็บ BAS ในกรอบแล้วกดตามภารกิจ กล่องใน flowchart จะติดไฟตามขั้นที่โค้ดกำลังทำงาน และดูค่าตัวแปรเปลี่ยนแบบสดๆ ได้
- **Flowchart สัญลักษณ์มาตรฐาน** ใช้ Terminator, Process, Predefined process, Decision และ Display พร้อมเลขบรรทัดในทุกกล่อง
- **ตารางไฟล์และบรรทัด** ทุกฟีเจอร์บอกว่าใช้ HTML CSS JS บรรทัดไหน selector ตัวไหน (`#id`, `.class`, `[data-*]`) และฟังก์ชันอะไรทำอะไรกับ element นั้น
- **คำอธิบาย 2 ระดับ** แบบเข้าใจง่ายและแบบตอบอาจารย์ พร้อมคำถามที่น่าจะโดนถาม
- **ลองทำให้พัง 42 แบบ** ดูโค้ดจริงที่ถูกลบหรือแก้ แล้วกด Preview เพื่อเทียบภาพก่อนและหลังแก้ ภาพทั้งหมดถ่ายจากเว็บที่แก้บรรทัดนั้นจริง F3 F4 F6 มีฟีเจอร์ละ 8 แบบ
- **ห้องทดลอง** ทุกฟีเจอร์เลือกบรรทัดไหนก็ได้ แล้วลบหรือแก้ เว็บ BAS จะโหลดใหม่จากโค้ดที่แก้จริง พร้อม console บอกว่า error เกิดตอนเปิดหน้าหรือตอนกด F3 F4 F6 มีเฉลยรายบรรทัดว่าลบแล้วเป็นบั๊กแบบไหน
- **แท็บฝึกข้อสอบ** 19 ข้อแบบ Predict Change Extend มีช่องเขียนคำตอบ เฉลยที่มีประโยค "เพราะ" และปุ่มรันโค้ดเฉลยในเว็บจริง

## โครงไฟล์

| ไฟล์ | คืออะไร |
| --- | --- |
| `index.html` | หน้าสมุดติวทั้งหมด ข้อมูลและสคริปต์อยู่ในไฟล์เดียว |
| `site/` | สำเนาเว็บ BAS ที่ใช้เล่นในกรอบ |
| `shots/` | ภาพหน้าจอที่มีหมายเลขกำกับ |
| `bk/` | ภาพก่อนและหลังของแต่ละการทำให้พัง |

## เปิดดูในเครื่อง

กรอบเว็บต้องเปิดผ่านเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิกไฟล์

```bash
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000
